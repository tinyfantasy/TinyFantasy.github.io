# Tiny Fantasy

A small island, a big story. Fight monsters, befriend villagers, fish, farm, raise pets and delve a dungeon, alone or with up to five friends.

Open `index.html` or play it on the web. The game is one HTML file plus the `music-*.m4a` files beside it.

## Controls

| Key | What it does |
| --- | --- |
| WASD / arrows | Move |
| E or Enter | Talk, fish, pick up, use |
| Space / click | Swing sword |
| Shift or K | Dodge roll |
| H or 1 | Eat something |
| I, Q, P, M | Bag, quests, pets, map |
| T, 5-8 | Chat and emotes (multiplayer) |
| N | Sound on / off |
| Esc | Menu |
